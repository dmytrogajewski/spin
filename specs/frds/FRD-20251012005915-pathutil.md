## Executive Summary

Implement a secure, reusable path validation and manipulation package (`pkg/pathutil`) that prevents path traversal attacks and ensures all file operations stay within workspace boundaries. This is a foundational package required by all file manipulation features in Spin.

---

## Background

### Problem Statement

Spin agents perform file operations based on AI-generated paths. Without robust path validation:
1. **Security Risk**: Path traversal attacks (`../../../etc/passwd`)
2. **Data Leakage**: Access to files outside workspace
3. **Symlink Exploits**: Following symlinks to escape workspace
4. **Inconsistent Validation**: Each package reimplementing validation

### Current State

- ❌ No centralized path validation
- ❌ No symlink escape detection
- ❌ Security vulnerabilities in file operations
- ❌ Code duplication across packages

### Goals

1. **Security**: Block all path traversal vectors
2. **Performance**: <1μs path validation overhead
3. **Reusability**: Public API in `pkg/` for all packages
4. **Correctness**: Handle edge cases (empty, `.`, `./`, trailing slashes)
5. **Testing**: ≥95% test coverage with comprehensive attack vectors

## Requirements

### Functional Requirements

#### FR-1: Path Validation

**FR-1.1**: Validate relative paths
- **Input**: String path
- **Output**: error or nil
- **Rule**: Must be relative (no leading `/` or drive letters)
- **Examples**:
  - `"src/main.go"` → valid ✓
  - `"/etc/passwd"` → error ✗
  - `"C:\Windows\System32"` → error ✗

**FR-1.2**: Detect parent directory traversal
- **Rule**: Reject paths containing `..` that escape workspace
- **Examples**:
  - `"src/../main.go"` → valid ✓ (stays in workspace)
  - `"../../../etc/passwd"` → error ✗
  - `"foo/../../../bar"` → error ✗

**FR-1.3**: Reject empty paths
- **Rule**: Empty string paths are invalid
- **Example**: `""` → error ✗

**FR-1.4**: Normalize paths before validation
- **Rule**: Clean paths using `filepath.Clean`
- **Examples**:
  - `"./src/main.go"` → `"src/main.go"`
  - `"src//main.go"` → `"src/main.go"`
  - `"src/./main.go"` → `"src/main.go"`

#### FR-2: Safe Path Joining

**FR-2.1**: Join root and relative path safely
- **Input**: root (absolute), relPath (relative)
- **Output**: absolute path or error
- **Rule**: Result must be within root directory tree

**FR-2.2**: Resolve symlinks during join
- **Rule**: If joined path is a symlink, resolve it and verify target is within root
- **Example**: `workspace/link → /etc/passwd` → error ✗

#### FR-3: Path Utilities

**FR-3.1**: Normalize paths
- **Function**: `NormalizePath(path string) string`
- **Behavior**: Clean and standardize path format

**FR-3.2**: Compute relative paths
- **Function**: `RelativePath(root, path string) (string, error)`
- **Behavior**: Return path relative to root

**FR-3.3**: Check workspace containment
- **Function**: `IsWithinRoot(root, path string) bool`
- **Behavior**: Check if path is within root directory

### Non-Functional Requirements

#### NFR-1: Performance
- Path validation: <1μs per operation
- Zero allocations in hot path (NormalizePath)
- Benchmarks included for all critical functions

#### NFR-2: Security
- Block all OWASP path traversal vectors
- Handle Unicode normalization attacks
- Resist timing attacks (constant-time where applicable)

#### NFR-3: Compatibility
- Cross-platform (Linux, macOS, Windows)
- Go 1.24+ standard library only
- No external dependencies

#### NFR-4: Quality
- Test coverage ≥95%
- `make lint` passes (zero errors)
- Race detector clean
- Cyclomatic complexity ≤10 per function

## Design

### Package Structure

### Public API

```go
package pathutil

import "errors"

// Errors
var (
    ErrAbsolutePath     = errors.New("absolute paths not allowed")
    ErrPathTraversal    = errors.New("path traversal detected")
    ErrEmptyPath        = errors.New("empty path not allowed")
    ErrSymlinkEscape    = errors.New("symlink escapes workspace")
)

// ValidateRelativePath validates that a path is relative and safe
func ValidateRelativePath(path string) error

// SafeJoin joins paths and validates the result stays within root
func SafeJoin(root, relPath string) (string, error)

// NormalizePath normalizes a path for consistent comparison
func NormalizePath(path string) string

// RelativePath returns path relative to root
func RelativePath(root, path string) (string, error)

// IsWithinRoot checks if path is within root directory
func IsWithinRoot(root, path string) bool
```

### Implementation Details

#### ValidateRelativePath Algorithm

```
1. Check if path is empty → ErrEmptyPath
2. Check if path is absolute → ErrAbsolutePath
3. Clean path with filepath.Clean
4. Split path into components
5. Track depth: start at 0
   - For each ".." → depth--
   - For each non-".." → depth++
   - If depth < 0 at any point → ErrPathTraversal
6. Return nil (valid)
```

#### SafeJoin Algorithm

```
1. Validate relPath with ValidateRelativePath
2. Join root + relPath → joined
3. Resolve absolute paths for both root and joined
4. Check if joined starts with root
5. If joined is symlink:
   - Resolve symlink target
   - Verify target is within root
6. Return joined or error
```

### Security Considerations

**Path Traversal Vectors**:
- Absolute paths: `/etc/passwd`, `C:\Windows`
- Parent traversal: `../../../etc/passwd`
- Hidden traversal: `foo/../../../bar`
- Null bytes: `foo\x00bar` (Go's filepath.Clean handles this)
- Unicode: `..%c0%af` (we normalize with filepath.Clean)

**Symlink Handling**:
- Resolve symlinks to their targets
- Verify targets are within workspace
- Handle broken symlinks gracefully

### Test Cases

#### Valid Relative Paths
1. `"src/main.go"` → valid
2. `"."` → valid
3. `"./src/main.go"` → valid (normalized)
4. `"src/../lib/util.go"` → valid (stays in workspace)
5. `"src/./main.go"` → valid (normalized)

#### Invalid Absolute Paths
1. `"/etc/passwd"` → ErrAbsolutePath
2. `"/home/user/file.txt"` → ErrAbsolutePath
3. `"C:\Windows\System32"` → ErrAbsolutePath (Windows)

#### Invalid Path Traversal
1. `"../../../etc/passwd"` → ErrPathTraversal
2. `"foo/../../../bar"` → ErrPathTraversal
3. `"../../.."` → ErrPathTraversal
4. `"src/../../.."` → ErrPathTraversal

#### Edge Cases
1. `""` → ErrEmptyPath
2. `"/"` → ErrAbsolutePath
3. `"."` → valid (current dir)
4. `".."` → ErrPathTraversal
5. `"src/"` → valid (trailing slash removed)
6. `"src//main.go"` → valid (normalized)

#### SafeJoin Tests
1. SafeJoin("/workspace", "src/main.go") → "/workspace/src/main.go"
2. SafeJoin("/workspace", "../etc/passwd") → error
3. SafeJoin with symlink inside workspace → valid
4. SafeJoin with symlink escaping workspace → error

#### Symlink Tests (requires temp filesystem)
1. Create symlink inside workspace → valid
2. Create symlink to parent directory → error
3. Create symlink to `/etc/passwd` → error
4. Create broken symlink → handle gracefully
