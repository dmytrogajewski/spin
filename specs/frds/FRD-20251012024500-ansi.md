# FRD-20251012024500: pkg/ansi - ANSI Escape Sequence Handling

**Feature ID:** FRD-20251012024500
**Feature Name:** pkg/ansi - ANSI Escape Sequence Handling
**Roadmap Reference:** [specs/tools-modules/ROADMAP.md](../tools-modules/ROADMAP.md) - Feature 1.3
**Priority:** P2 (Required for TUI polish)
**Created:** 2025-10-12
**Status:** In Development

---

## Overview

Create a public `pkg/ansi` package that provides robust ANSI escape sequence handling for terminal formatting, including parsing, stripping, generation, and styling. This extracts and enhances functionality from `internal/ui/term/ansi.go` for reuse across the codebase.

### Goals

1. Extract ANSI functionality from `internal/ui/term` into reusable `pkg/ansi`
2. Provide comprehensive ANSI escape sequence parsing and stripping
3. Enable fluent API for text styling (colors, bold, underline, etc.)
4. Support structured parsing of ANSI-formatted text
5. Maintain backward compatibility during migration

### Non-Goals

- Complete ANSI specification support (only common sequences)
- 256-color or true-color support (basic 16 colors sufficient)
- Cursor positioning (remains in `internal/ui/term`)
- Screen buffer management

---

## Background

Currently, `internal/ui/term/ansi.go` provides basic terminal control sequences (cursor, clear line, etc.) but lacks:
- ANSI escape sequence stripping
- Color and style formatting
- Structured parsing of ANSI text
- Visual length calculation (excluding escape codes)

Many TUI components need to:
- Calculate visual width of text containing ANSI codes
- Strip formatting for logging or storage
- Parse terminal output containing colors
- Generate styled output consistently

The `pkg/ansi` package will centralize this functionality.

## Requirements

### Functional Requirements

#### FR1: Strip ANSI Escape Sequences

```go
// Strip removes all ANSI escape sequences from text
// Returns plain text without any formatting codes
text := "\x1b[31mRed text\x1b[0m"
plain := ansi.Strip(text)  // "Red text"
```

**Acceptance Criteria:**
- Removes all CSI (Control Sequence Introducer) codes
- Removes SGR (Select Graphic Rendition) codes
- Handles malformed sequences gracefully
- Zero-copy for strings without ANSI codes
- Performance: O(n) single pass

#### FR2: Calculate Visual Length

```go
// Length returns the visual length of text (excluding ANSI codes)
// Used for proper alignment and wrapping
text := "\x1b[1m\x1b[32mBold Green\x1b[0m"
len := ansi.Length(text)  // 10 (visible characters only)
```

**Acceptance Criteria:**
- Counts only visible characters
- Excludes all ANSI escape sequences
- Handles multi-byte UTF-8 correctly (via rune counting)
- Performance: O(n)

#### FR3: Color and Style Constants

```go
// Standard ANSI color codes
const (
    Reset = "\x1b[0m"

    // Foreground colors (30-37)
    Black   = "\x1b[30m"
    Red     = "\x1b[31m"
    Green   = "\x1b[32m"
    Yellow  = "\x1b[33m"
    Blue    = "\x1b[34m"
    Magenta = "\x1b[35m"
    Cyan    = "\x1b[36m"
    White   = "\x1b[37m"

    // Styles (1-4)
    Bold      = "\x1b[1m"
    Dim       = "\x1b[2m"
    Italic    = "\x1b[3m"
    Underline = "\x1b[4m"
)
```

**Acceptance Criteria:**
- Standard ANSI SGR codes (widely compatible)
- No 256-color or RGB (keeping it simple)
- Zero-allocation constants

#### FR4: Fluent Style Builder

```go
// Style provides chainable text styling
styled := ansi.New("Error").Red().Bold().String()
// Output: "\x1b[31m\x1b[1mError\x1b[0m"

// Multiple styles can be chained
msg := ansi.New("Warning").Yellow().Underline().String()

// Empty styles return plain text
plain := ansi.New("Text").String()  // "Text"
```

**Acceptance Criteria:**
- Fluent API for chaining styles
- Automatic reset at end (`\x1b[0m`)
- Methods: `Red()`, `Green()`, `Yellow()`, `Blue()`, `Magenta()`, `Cyan()`, `White()`, `Bold()`, `Dim()`, `Italic()`, `Underline()`
- `String()` returns final styled string
- Zero-allocation for no-style case

#### FR5: Parse ANSI Text into Segments

```go
// Segment represents a styled text segment
type Segment struct {
    Text       string
    Foreground string  // "red", "green", etc. or ""
    Background string  // (reserved for future)
    Bold       bool
    Dim        bool
    Italic     bool
    Underline  bool
}

// Parse breaks ANSI text into structured segments
text := "\x1b[31mRed\x1b[0m Normal \x1b[1mBold\x1b[0m"
segments := ansi.Parse(text)
// segments[0]: {Text: "Red", Foreground: "red"}
// segments[1]: {Text: " Normal "}
// segments[2]: {Text: "Bold", Bold: true}
```

**Acceptance Criteria:**
- Parses common SGR sequences
- Tracks cumulative state changes
- Handles reset codes correctly
- Returns plain segments for unstyled text
- Robust to malformed sequences (best-effort)

### API Design

#### ansi.go

```go
package ansi

import "regexp"

// ANSI escape sequence regex (CSI sequences)
var ansiRegex = regexp.MustCompile(`\x1b\[[0-9;]*[a-zA-Z]`)

// Strip removes all ANSI escape sequences from text
func Strip(text string) string {
    return ansiRegex.ReplaceAllString(text, "")
}

// Length returns the visual length of text (excluding ANSI codes)
func Length(text string) int {
    plain := Strip(text)
    return len([]rune(plain))  // UTF-8 aware
}

// Color and style constants (as defined in FR3)
```

#### style.go

```go
package ansi

import "strings"

// New creates a new Style builder for the given text
func New(text string) *Style {
    return &Style{
        text:  text,
        codes: make([]string, 0, 4),  // Pre-allocate for common case
    }
}

// Red applies red foreground color
func (s *Style) Red() *Style {
    s.codes = append(s.codes, Red)
    return s
}

// Green, Yellow, Blue, etc. (similar pattern)

// Bold applies bold styling
func (s *Style) Bold() *Style {
    s.codes = append(s.codes, Bold)
    return s
}

// Underline, Dim, Italic (similar pattern)

// String returns the styled text with ANSI codes and reset
func (s *Style) String() string {
    if len(s.codes) == 0 {
        return s.text
    }

    var b strings.Builder
    b.Grow(len(s.text) + len(s.codes)*5 + 4)  // Estimate size

    for _, code := range s.codes {
        b.WriteString(code)
    }
    b.WriteString(s.text)
    b.WriteString(Reset)

    return b.String()
}
```

#### parse.go

```go
package ansi

import "strings"

// Parse parses ANSI-formatted text into structured segments
func Parse(text string) []Segment {
    segments := make([]Segment, 0)

    current := Segment{}
    inEscape := false
    escapeSeq := ""

    for i := 0; i < len(text); i++ {
        ch := text[i]

        if ch == '\x1b' {
            // Start of escape sequence
            if len(current.Text) > 0 {
                segments = append(segments, current)
                current = Segment{
                    // Inherit previous formatting
                    Foreground: current.Foreground,
                    Background: current.Background,
                    Bold:       current.Bold,
                    Dim:        current.Dim,
                    Italic:     current.Italic,
                    Underline:  current.Underline,
                }
            }
            inEscape = true
            escapeSeq = string(ch)
            continue
        }

        if inEscape {
            escapeSeq += string(ch)
            if isTerminator(ch) {
                // Parse and apply escape sequence
                applyEscapeSequence(escapeSeq, &current)
                inEscape = false
                escapeSeq = ""
            }
            continue
        }

        current.Text += string(ch)
    }

    if len(current.Text) > 0 {
        segments = append(segments, current)
    }

    return segments
}

func isTerminator(ch byte) bool {
    return (ch >= 'A' && ch <= 'Z') || (ch >= 'a' && ch <= 'z')
}

func applyEscapeSequence(seq string, seg *Segment) {
    // Parse SGR codes like "\x1b[31m", "\x1b[1;32m", etc.
    if !strings.HasPrefix(seq, "\x1b[") || !strings.HasSuffix(seq, "m") {
        return  // Not an SGR code
    }

    // Extract numeric parameters
    params := strings.TrimPrefix(strings.TrimSuffix(seq, "m"), "\x1b[")
    codes := strings.Split(params, ";")

    for _, code := range codes {
        switch code {
        case "0":
            // Reset all
            seg.Foreground = ""
            seg.Background = ""
            seg.Bold = false
            seg.Dim = false
            seg.Italic = false
            seg.Underline = false
        case "1":
            seg.Bold = true
        case "2":
            seg.Dim = true
        case "3":
            seg.Italic = true
        case "4":
            seg.Underline = true
        case "30":
            seg.Foreground = "black"
        case "31":
            seg.Foreground = "red"
        case "32":
            seg.Foreground = "green"
        case "33":
            seg.Foreground = "yellow"
        case "34":
            seg.Foreground = "blue"
        case "35":
            seg.Foreground = "magenta"
        case "36":
            seg.Foreground = "cyan"
        case "37":
            seg.Foreground = "white"
        // Add background colors (40-47) if needed
        }
    }
}
```

## Risks and Mitigations

### Risk 1: Regex Performance

**Mitigation:** Focus on common sequences (SGR), document limitations, extensible design.

### Risk 3: Migration Breaks Existing Code
**Mitigation:** Maintain backward compatibility, incremental migration, comprehensive testing.

### Risk 4: UTF-8 Handling Complexity
**Mitigation:** Use `[]rune` for length calculation, test with various UTF-8 strings.
