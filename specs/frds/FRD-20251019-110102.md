### Phase 2: Test Development

#### Table-Driven Test Pattern (AGENTS.md standard)

```go
func TestFunctionName(t *testing.T) {
    tests := []struct {
        name    string
        input   InputType
        want    OutputType
        wantErr bool
    }{
        {
            name:    "happy path",
            input:   validInput,
            want:    expectedOutput,
            wantErr: false,
        },
        {
            name:    "edge case - empty input",
            input:   emptyInput,
            want:    nil,
            wantErr: true,
        },
        // Add error paths, boundary conditions, race conditions
    }
    
    for _, tt := range tests {
        t.Run(tt.name, func(t *testing.T) {
            got, err := FunctionName(tt.input)
            if (err != nil) != tt.wantErr {
                t.Errorf("error = %v, wantErr %v", err, tt.wantErr)
                return
            }
            if !reflect.DeepEqual(got, tt.want) {
                t.Errorf("got %v, want %v", got, tt.want)
            }
        })
    }
}
```

## Testing Strategy

### Unit Tests

- **Focus:** Individual functions, pure logic
- **Mocking:** Minimal, only for external dependencies (LLM, filesystem)
- **Coverage target:** 85-90%

### Integration Tests

- **Focus:** Component interactions (Manager + Tools, Approval + Executor)
- **Mocking:** Interface boundaries only
- **Coverage target:** 80%

### E2E Tests

- **Focus:** Complete user flows (command execution, approval workflows)
- **Mocking:** None - test real behavior
- **Coverage target:** Critical paths at 90%+

## Hanging Test Investigation

Tests currently hang during full suite execution. Investigation steps:

1. Run individual package tests with timeout: `go test -timeout 30s ./...`
2. Identify packages that timeout
3. Check for:
   - Deadlocks in goroutines
   - Unbuffered channels without readers
   - Context cancellation not propagated
   - Infinite loops in edge cases
4. Add `-race` flag to detect race conditions causing hangs
