# Spin Security Modules - Technical Documentation

## Overview

The security subsystem of Spin implements a multi-layered defense-in-depth approach to safely execute untrusted commands generated by an AI agent. This document covers three primary security packages:

1. **internal/security/policy** - Command validation and classification
2. **internal/security/sandbox** - Platform-specific filesystem isolation
3. **internal/security/hardening** - Process-level security measures

## Architecture

```
┌──────────────────────────────────────────────────────────┐
│              Command Execution Request                   │
└───────────────────────┬──────────────────────────────────┘
                        │
┌───────────────────────▼──────────────────────────────────┐
│            Layer 1: Execution Policy                     │
│  • Parse command and arguments                           │
```

## Module 1: Policy Engine

**Package:** `internal/security/policy`  
**Purpose:** Classify proposed commands into safety categories

### Core Concept

The execution policy engine parses shell commands and matches them against a declarative policy to determine safety classification without executing the command.

### Safety Classifications

```go
// Classification represents command safety level
type Classification int

const (
    // Safe commands execute automatically
    ClassificationSafe Classification = iota
    
    // Interactive commands need approval
    ClassificationInteractive
    
    // Dangerous commands need strong approval
    ClassificationDangerous
    
    // Forbidden commands never execute
    ClassificationForbidden
    
    // Unverified commands have unknown safety
    ClassificationUnverified
)

func (c Classification) String() string {
    return [...]string{"safe", "interactive", "dangerous", "forbidden", "unverified"}[c]
}

func (c Classification) NeedsApproval() bool {
    return c >= ClassificationInteractive && c <= ClassificationDangerous
}
```

#### Examples by Classification

**Safe:**
- `ls`, `cat README.md`, `git status`, `pwd`
- Read-only operations with no side effects

**Interactive:**
- `cp src.txt dest.txt`, `npm install`, `mkdir build`
- Write operations within workspace

**Dangerous:**
- `rm -rf dir`, `git push --force`, `sudo apt install`
- Destructive or system-level operations

**Forbidden:**
- `rm -rf /`, `:(){ :|:& };:`, `curl | bash`
- Catastrophic or malicious commands

**Unverified:**
- Unknown commands or complex pipelines
- Safety cannot be determined from policy

#### Policy Manager
**File:** `policy.go`

```go
// Manager implements Policy interface
type Manager struct {
    rules       []*Rule
    matchers    map[string]*RuleMatcher
    customPath  string
    mu          sync.RWMutex
}

// NewManager creates a policy manager
func NewManager(opts ...Option) (*Manager, error) {
    m := &Manager{
        matchers: make(map[string]*RuleMatcher),
    }
    
    // Load default policy
    if err := m.loadDefaultPolicy(); err != nil {
        return nil, fmt.Errorf("load default policy: %w", err)
    }
    
    // Apply options
    for _, opt := range opts {
        opt(m)
    }
    
    return m, nil
}

// Check validates a command
func (m *Manager) Check(cmd Command) (*ValidationResult, error) {
    m.mu.RLock()
    defer m.mu.RUnlock()
    
    // 1. Check forbidden patterns first
    if result := m.checkForbidden(cmd); result != nil {
        return result, nil
    }
    
    // 2. Find matching rule
    matcher, ok := m.matchers[cmd.Program]
    if !ok {
        return &ValidationResult{
            Classification: ClassificationUnverified,
            Reason:         fmt.Sprintf("no rule found for '%s'", cmd.Program),
        }, nil
    }
    
    // 3. Match arguments
    match, err := matcher.Match(cmd)
    if err != nil {
        return nil, fmt.Errorf("match error: %w", err)
    }
    
    if match == nil {
        return &ValidationResult{
            Classification: ClassificationUnverified,
            Reason:         fmt.Sprintf("arguments don't match any pattern for '%s'", cmd.Program),
        }, nil
    }
    
    // 4. Classify based on matched rule
    return &ValidationResult{
        Classification: match.Rule.Classification,
        MatchedRule:    match.Rule,
        WriteablePaths: match.WriteablePaths,
        ReadablePaths:  match.ReadablePaths,
    }, nil
}
```

```go
// Rule represents a command validation rule
type Rule struct {
    // Program is the command name
    Program string
    
    // Classification is the safety level
    Classification Classification
    
    // Flags are allowed flags (e.g., "-r", "--recursive")
    Flags []string
    
    // Options are flags with values (e.g., "-o output")
    Options []Option
    
    // Args defines expected argument pattern
    Args []ArgPattern
    
    // SystemPath is trusted executable paths
    SystemPath []string
    
    // Description explains the rule
    Description string
    
    // Examples for testing
    ShouldMatch    [][]string
    ShouldNotMatch [][]string
}

// Option represents a flag with value
type Option struct {
    Name       string   // -o or --output
    Aliases    []string // Alternative names
    HasValue   bool     // Requires value
    ValueType  ArgType  // Type of value
}

// ArgPattern defines expected argument
type ArgPattern struct {
    Type   ArgType
    Greedy bool  // Consumes remaining arguments
}

// ArgType classifies argument types
type ArgType int

const (
    ArgTypeAny ArgType = iota
    ArgTypeReadFile
    ArgTypeWriteFile
    ArgTypeReadDir
    ArgTypeWriteDir
    ArgTypeLiteral
)
```

#### Argument Matching
**File:** `matcher.go`

```go
// RuleMatcher matches commands against a rule
type RuleMatcher struct {
    rule *Rule
}

// Match attempts to match command against rule
func (m *RuleMatcher) Match(cmd Command) (*MatchResult, error) {
    // 1. Validate flags
    unknownFlags := m.findUnknownFlags(cmd.Args)
    if len(unknownFlags) > 0 {
        return nil, nil  // No match
    }
    
    // 2. Parse options
    opts, remaining := m.parseOptions(cmd.Args)
    
    // 3. Match positional arguments
    match, err := m.matchArgs(remaining)
    if err != nil {
        return nil, err
    }
    
    return match, nil
}

// matchArgs matches positional arguments against patterns
func (m *RuleMatcher) matchArgs(args []string) (*MatchResult, error) {
    result := &MatchResult{
        Rule: m.rule,
    }
    
    argIdx := 0
    for _, pattern := range m.rule.Args {
        if argIdx >= len(args) {
            return nil, nil  // Not enough args
        }
        
        if pattern.Greedy {
            // Consume all remaining args
            for argIdx < len(args) {
                if err := m.classifyArg(args[argIdx], pattern.Type, result); err != nil {
                    return nil, err
                }
                argIdx++
            }
        } else {
            // Consume single arg
            if err := m.classifyArg(args[argIdx], pattern.Type, result); err != nil {
                return nil, err
            }
            argIdx++
        }
    }
    
    if argIdx < len(args) {
        return nil, nil  // Too many args
    }
    
    return result, nil
}

// classifyArg classifies an argument by type
func (m *RuleMatcher) classifyArg(arg string, typ ArgType, result *MatchResult) error {
    switch typ {
    case ArgTypeReadFile:
        result.ReadablePaths = append(result.ReadablePaths, arg)
    case ArgTypeWriteFile:
        result.WriteablePaths = append(result.WriteablePaths, arg)
    case ArgTypeReadDir:
        result.ReadablePaths = append(result.ReadablePaths, arg)
    case ArgTypeWriteDir:
        result.WriteablePaths = append(result.WriteablePaths, arg)
    case ArgTypeAny:
        // No classification needed
    case ArgTypeLiteral:
        // Validate exact match
    }
    return nil
}

// MatchResult contains matching information
type MatchResult struct {
    Rule           *Rule
    ReadablePaths  []string
    WriteablePaths []string
}
```

### Integration with Core

```go
// In internal/core/executor.go
func (e *Executor) Execute(ctx context.Context, cmd Command) (*Result, error) {
    // 1. Validate with policy
    validation, err := e.policy.Check(cmd)
    if err != nil {
        return nil, fmt.Errorf("policy check: %w", err)
    }
    
    // 2. Handle classification
    switch validation.Classification {
    case ClassificationForbidden:
        return nil, fmt.Errorf("forbidden command: %s", validation.Reason)
    
    case ClassificationDangerous, ClassificationInteractive:
        // Request approval
        if !e.requestApproval(ctx, cmd, validation) {
            return nil, errors.New("user denied approval")
        }
    
    case ClassificationUnverified:
        // Always request approval for unknown commands
        if !e.requestApproval(ctx, cmd, validation) {
            return nil, errors.New("user denied approval")
        }
    
    case ClassificationSafe:
        // Continue to execution
    }
    
    // 3. Check writeable paths are in workspace
    if err := e.validateWorkspacePaths(validation.WriteablePaths); err != nil {
        return nil, fmt.Errorf("path validation: %w", err)
    }
    
    // 4. Apply sandbox and execute
    return e.executeWithSandbox(ctx, cmd)
}
```

### Sandbox Interface

```go
// Sandbox provides OS-level command isolation
type Sandbox interface {
    // Wrap wraps a command with sandbox restrictions
    Wrap(cmd *exec.Cmd, opts SandboxOptions) error
    
    // Supported returns true if sandbox is available
    Supported() bool
    
    // Mode returns current sandbox mode
    Mode() Mode
}

// SandboxOptions configures sandbox behavior
type SandboxOptions struct {
    Mode         Mode
    ReadPaths    []string
    WritePaths   []string
    BlockNetwork bool
    WorkDir      string
}

// Mode defines sandbox restriction level
type Mode int

const (
    // ModeReadOnly allows reading workspace, no writes
    ModeReadOnly Mode = iota
    
    // ModeWorkspaceWrite allows writes within workspace
    ModeWorkspaceWrite
    
    // ModeFullAccess disables sandbox (containers only)
    ModeFullAccess
)
```

### Linux Implementation (Landlock)

**File:** `sandbox_linux.go`

```go
//go:build linux

package sandbox

import (
    "fmt"
    "os/exec"
    "syscall"
    
    "golang.org/x/sys/unix"
)

// LinuxSandbox implements Sandbox using Landlock LSM
type LinuxSandbox struct {
    mode Mode
}

// NewSandbox creates a Linux sandbox
func NewSandbox(mode Mode) (Sandbox, error) {
    // Check Landlock support
    if !landlockSupported() {
        return &NoopSandbox{}, fmt.Errorf("landlock not supported (kernel 5.13+ required)")
    }
    
    return &LinuxSandbox{mode: mode}, nil
}

// Wrap applies Landlock restrictions to command
func (s *LinuxSandbox) Wrap(cmd *exec.Cmd, opts SandboxOptions) error {
    // Create Landlock ruleset
    ruleset, err := s.createRuleset(opts)
    if err != nil {
        return fmt.Errorf("create ruleset: %w", err)
    }
    
    // Apply via syscall before exec
    cmd.SysProcAttr = &syscall.SysProcAttr{
        AmbientCaps: []uintptr{},
        Cloneflags:  0,
    }
    
    // Pre-exec function applies Landlock
    preExec := func() {
        if err := s.applyLandlock(ruleset); err != nil {
            panic(fmt.Sprintf("apply landlock: %v", err))
        }
    }
    
    if cmd.SysProcAttr == nil {
        cmd.SysProcAttr = &syscall.SysProcAttr{}
    }
    
    // Note: Can't set preExec in SysProcAttr directly in modern Go
    // Use separate helper binary approach (see below)
    
    return s.wrapWithHelper(cmd, ruleset)
}

// wrapWithHelper re-execs through helper that applies Landlock
func (s *LinuxSandbox) wrapWithHelper(cmd *exec.Cmd, ruleset *LandlockRuleset) error {
    // Serialize ruleset
    data, err := ruleset.Serialize()
    if err != nil {
        return err
    }
    
    // Wrap: spin-sandbox --ruleset=<data> -- <original command>
    wrapped := exec.Cmd{
        Path: "/proc/self/exe",  // Re-exec self
        Args: append(
            []string{"spin-sandbox", "--ruleset=" + data, "--"},
            cmd.Args...,
        ),
        Env:    cmd.Env,
        Dir:    cmd.Dir,
        Stdin:  cmd.Stdin,
        Stdout: cmd.Stdout,
        Stderr: cmd.Stderr,
    }
    
    *cmd = wrapped
    return nil
}

// landlockSupported checks if Landlock is available
func landlockSupported() bool {
    // Try to create a Landlock ruleset

            HandledAccessFS: unix.LANDLOCK_ACCESS_FS_READ_FILE,
        },
        0,
    )
    if err != nil {

    }

    return true
```

```go
//go:build linux

package sandbox

import (
    "fmt"
    "os"
    
    "golang.org/x/sys/unix"
)

// LandlockRuleset represents Landlock access rules
type LandlockRuleset struct {
    ReadPaths    []string
    WritePaths   []string
    BlockNetwork bool
}

// Apply applies the Landlock ruleset to current process
func (r *LandlockRuleset) Apply() error {
    // 1. Create ruleset
    handledAccess := uint64(
        unix.LANDLOCK_ACCESS_FS_EXECUTE |
        unix.LANDLOCK_ACCESS_FS_WRITE_FILE |
        unix.LANDLOCK_ACCESS_FS_READ_FILE |
        unix.LANDLOCK_ACCESS_FS_READ_DIR |
        unix.LANDLOCK_ACCESS_FS_REMOVE_DIR |
        unix.LANDLOCK_ACCESS_FS_REMOVE_FILE |
        unix.LANDLOCK_ACCESS_FS_MAKE_CHAR |
        unix.LANDLOCK_ACCESS_FS_MAKE_DIR |
        unix.LANDLOCK_ACCESS_FS_MAKE_REG |
        unix.LANDLOCK_ACCESS_FS_MAKE_SOCK |
        unix.LANDLOCK_ACCESS_FS_MAKE_FIFO |
        unix.LANDLOCK_ACCESS_FS_MAKE_BLOCK |
        unix.LANDLOCK_ACCESS_FS_MAKE_SYM,
    )
    
    rulesetFd, err := unix.LandlockCreateRuleset(
        &unix.LandlockRulesetAttr{
            HandledAccessFS: handledAccess,
        },
        0,
    )
    if err != nil {
        return fmt.Errorf("create ruleset: %w", err)
    }
    defer unix.Close(rulesetFd)
    
    // 2. Add read paths
    for _, path := range r.ReadPaths {
        if err := r.addPathRule(rulesetFd, path, false); err != nil {
            return fmt.Errorf("add read path %s: %w", path, err)
        }
    }
    
    // 3. Add write paths
    for _, path := range r.WritePaths {
        if err := r.addPathRule(rulesetFd, path, true); err != nil {
            return fmt.Errorf("add write path %s: %w", path, err)
        }
    }
    
    // 4. Restrict self
    if err := unix.LandlockRestrictSelf(rulesetFd, 0); err != nil {
        return fmt.Errorf("restrict self: %w", err)
    }
    
    return nil
}

// addPathRule adds a path access rule
func (r *LandlockRuleset) addPathRule(rulesetFd int, path string, write bool) error {
    // Open path to get file descriptor
    fd, err := unix.Open(path, unix.O_PATH|unix.O_CLOEXEC, 0)
    if err != nil {
        return fmt.Errorf("open path: %w", err)
    }
    defer unix.Close(fd)
    
    // Determine allowed access
    var allowedAccess uint64
    if write {
        allowedAccess = unix.LANDLOCK_ACCESS_FS_EXECUTE |
            unix.LANDLOCK_ACCESS_FS_WRITE_FILE |
            unix.LANDLOCK_ACCESS_FS_READ_FILE |
            unix.LANDLOCK_ACCESS_FS_READ_DIR |
            unix.LANDLOCK_ACCESS_FS_MAKE_DIR |
            unix.LANDLOCK_ACCESS_FS_MAKE_REG |
            unix.LANDLOCK_ACCESS_FS_REMOVE_FILE |
            unix.LANDLOCK_ACCESS_FS_REMOVE_DIR
    } else {
        allowedAccess = unix.LANDLOCK_ACCESS_FS_EXECUTE |
            unix.LANDLOCK_ACCESS_FS_READ_FILE |
            unix.LANDLOCK_ACCESS_FS_READ_DIR
    }
    
    // Add rule
    err = unix.LandlockAddRule(
        rulesetFd,
        unix.LANDLOCK_RULE_PATH_BENEATH,
        &unix.LandlockPathBeneathAttr{
            AllowedAccess: allowedAccess,
            ParentFd:      fd,
        },
        0,
    )
    if err != nil {
        return fmt.Errorf("add rule: %w", err)
    }
    
    return nil
}
```

```go
//go:build darwin

package sandbox

import (
    "fmt"
    "os"
    "os/exec"
    "path/filepath"
)

// DarwinSandbox implements Sandbox using sandbox-exec
type DarwinSandbox struct {
    mode Mode
}

// NewSandbox creates a macOS sandbox
func NewSandbox(mode Mode) (Sandbox, error) {
    // Check sandbox-exec exists
    if _, err := exec.LookPath("sandbox-exec"); err != nil {
        return &NoopSandbox{}, fmt.Errorf("sandbox-exec not found")
    }
    
    return &DarwinSandbox{mode: mode}, nil
}

// Wrap applies Seatbelt sandbox to command
func (s *DarwinSandbox) Wrap(cmd *exec.Cmd, opts SandboxOptions) error {
    // Generate Seatbelt profile
    profile, err := s.generateProfile(opts)
    if err != nil {
        return fmt.Errorf("generate profile: %w", err)
    }
    
    // Write profile to temp file
    profilePath := filepath.Join(os.TempDir(), "spin-sandbox.sb")
    if err := os.WriteFile(profilePath, []byte(profile), 0600); err != nil {
        return fmt.Errorf("write profile: %w", err)
    }
    
    // Wrap: sandbox-exec -f profile.sb command args...
    wrapped := exec.Cmd{
        Path: "/usr/bin/sandbox-exec",
        Args: append(
            []string{"sandbox-exec", "-f", profilePath},
            cmd.Args...,
        ),
        Env:    cmd.Env,
        Dir:    cmd.Dir,
        Stdin:  cmd.Stdin,
        Stdout: cmd.Stdout,
        Stderr: cmd.Stderr,
    }
    
    *cmd = wrapped
    return nil
}

// generateProfile creates Seatbelt profile
func (s *DarwinSandbox) generateProfile(opts SandboxOptions) (string, error) {
    profile := `(version 1)
(debug deny)
(allow default)

;; Deny all file writes by default
(deny file-write*)

;; Allow read access
`
    
    for _, path := range opts.ReadPaths {
        profile += fmt.Sprintf("(allow file-read* (subpath \"%s\"))\n", path)
    }
    
    profile += "\n;; Allow write access\n"
    for _, path := range opts.WritePaths {
        profile += fmt.Sprintf("(allow file-write* (subpath \"%s\"))\n", path)
    }
    
    if opts.BlockNetwork {
        profile += "\n;; Block network\n"
        profile += "(deny network*)\n"
    }
    
    return profile, nil
}
```

```go
    opts := SandboxOptions{
        Mode:    mode,
        WorkDir: workDir,

    switch mode {
    case ModeReadOnly:
        opts.ReadPaths = []string{
            workDir,

            "/bin",
            "/lib",
            "/lib64",
            "/etc",

        opts.WritePaths = []string{}

        opts.ReadPaths = []string{

            "/usr",
            "/bin",
            "/lib",
            "/lib64",

        }
        opts.WritePaths = []string{workDir}
        opts.BlockNetwork = true
    
    case ModeFullAccess:
        // No restrictions
        opts.ReadPaths = []string{"/"}
        opts.WritePaths = []string{"/"}
        opts.BlockNetwork = false
    }
    
    return opts
}
```

```go
package hardening

import (
    "fmt"
    "log/slog"
    "os"
)

// Apply applies all hardening measures
// Should be called as early as possible in main()
func Apply() error {
    var errs []error
    
    // 1. Disable core dumps
    if err := disableCoreDumps(); err != nil {
        errs = append(errs, fmt.Errorf("disable core dumps: %w", err))
    } else {
        slog.Debug("disabled core dumps")
    }
    
    // 2. Disable ptrace
    if err := disablePtrace(); err != nil {
        errs = append(errs, fmt.Errorf("disable ptrace: %w", err))
    } else {
        slog.Debug("disabled ptrace")
    }
    
    // 3. Remove dangerous env vars
    if err := sanitizeEnvironment(); err != nil {
        errs = append(errs, fmt.Errorf("sanitize environment: %w", err))
    } else {
        slog.Debug("sanitized environment")
    }
    
    if len(errs) > 0 {
        return fmt.Errorf("hardening errors: %v", errs)
    }
    
    return nil
}

// sanitizeEnvironment removes dangerous environment variables
func sanitizeEnvironment() error {
    dangerous := []string{
        // Linux
        "LD_PRELOAD",
        "LD_LIBRARY_PATH",
        "LD_AUDIT",
        "LD_BIND_NOW",
        
        // macOS
        "DYLD_INSERT_LIBRARIES",
        "DYLD_LIBRARY_PATH",
        "DYLD_FRAMEWORK_PATH",
        "DYLD_FALLBACK_LIBRARY_PATH",
        "DYLD_FALLBACK_FRAMEWORK_PATH",
    }
    
    for _, key := range dangerous {
        if _, exists := os.LookupEnv(key); exists {
            slog.Warn("removing dangerous environment variable", "key", key)
            os.Unsetenv(key)
        }
    }
    
    return nil
}
```

## Integration Example

### Complete Secure Execution Flow

```go
package main

import (
    "context"
    "fmt"
    
    "github.com/yourusername/spin/internal/core"
    _ "github.com/yourusername/spin/internal/security/hardening"
    "github.com/yourusername/spin/internal/security/policy"
    "github.com/yourusername/spin/internal/security/sandbox"
)

func secureExecute(ctx context.Context, cmdline string) error {
    // 1. Parse command
    cmd, err := policy.ParseCommand(cmdline)
    if err != nil {
        return fmt.Errorf("parse: %w", err)
    }
    
    // 2. Check policy
    pol, _ := policy.NewManager()
    validation, err := pol.Check(cmd)
    if err != nil {
        return fmt.Errorf("policy check: %w", err)
    }
    
    // 3. Handle classification
    switch validation.Classification {
    case policy.ClassificationForbidden:
        return fmt.Errorf("forbidden: %s", validation.Reason)
    
    case policy.ClassificationDangerous:
        fmt.Printf("⚠️  Dangerous command: %s\n", validation.Reason)
        fmt.Printf("   Will modify: %v\n", validation.WriteablePaths)
        if !promptApproval() {
            return fmt.Errorf("user denied")
        }
    
    case policy.ClassificationInteractive:
        fmt.Printf("Interactive command, will modify: %v\n", validation.WriteablePaths)
        if !promptApproval() {
            return fmt.Errorf("user denied")
        }
    }
    
    // 4. Create sandboxed command
    execCmd := exec.CommandContext(ctx, cmd.Program, cmd.Args...)
    
    sb, err := sandbox.NewSandbox(sandbox.ModeWorkspaceWrite)
    if err != nil {
        return fmt.Errorf("create sandbox: %w", err)
    }
    
    opts := sandbox.GetDefaultOptions(sandbox.ModeWorkspaceWrite, "/workspace")
    if err := sb.Wrap(execCmd, opts); err != nil {
        return fmt.Errorf("wrap sandbox: %w", err)
    }
    
    // 5. Execute
    output, err := execCmd.CombinedOutput()
    if err != nil {
        return fmt.Errorf("execute: %w\nOutput: %s", err, output)
    }
    
    fmt.Printf("Output: %s\n", output)
    return nil
}
```

## Security Best Practices

### For Users

1. **Use Default Sandbox Mode:**
   ```bash
   spin  # defaults to workspace-write
   ```

2. **Review Dangerous Commands:**
   - Always review commands classified as "dangerous"
   - Understand what files will be modified

3. **Run in Containers for Maximum Isolation:**
   ```bash
   docker run -v $(pwd):/workspace spin --sandbox full-access
   ```

4. **Use Custom Policies:**
   ```bash
   spin --policy ./custom.policy
   ```

### For Developers

1. **Extend Execution Policy:**
   ```go
   // Add custom rules
   customRules := []*policy.Rule{
       {
           Program:        "mytool",
           Classification: policy.ClassificationSafe,
           Args:           []policy.ArgPattern{{Type: policy.ArgTypeAny}},
       },
   }
   
   pol, _ := policy.NewManager(
       policy.WithCustomRules(customRules),
   )
   ```

2. **Test Sandbox Behavior:**
   ```bash
   go test ./internal/security/sandbox/...
   ```

3. **Never Log Credentials:**
   ```go
   // Bad
   slog.Info("API call", "api_key", apiKey)
   
   // Good
   slog.Info("API call", "has_key", apiKey != "")
   ```

4. **Zeroize Sensitive Memory:**
   ```go
   import "github.com/awnumar/memguard"
   
   secret := memguard.NewBufferFromBytes(apiKey)
   defer secret.Destroy()
   ```
